# Biblioteca Triple Peaks - Projeto 2

Pagina de apresentacao da biblioteca Triple Peaks, desenvolvida como o segundo projeto do programa de desenvolvimento web da TripleTen. O foco esta na construcao de uma interface semantica, organizada e responsiva usando apenas tecnologias front-end fundamentais.

## Recursos

- Cabecalho com logotipo e navegacao.
- Apresentacao da biblioteca e seus espacos.
- Conteudo editorial com imagem de destaque.
- Secoes organizadas para leitura em diferentes telas.
- Rodape com informacoes institucionais.

## Tecnologias e praticas

- HTML5 semantico.
- CSS3.
- Flexbox para layout e alinhamento.
- Normalize CSS para consistencia entre navegadores.
- Imagens, SVG e favicon locais.

## Organizacao

- `index.html`: estrutura e conteudo.
- `styles/style.css`: estilos da pagina.
- `images/`: logotipo, imagens e fundo.
- `vendor/normalize.css`: normalizacao CSS.

## Como executar

Abra `index.html` em um navegador ou sirva a pasta com um servidor estatico local.
